Pavo AI 画布使用方法

推荐：先图后视频，少试错
  1. 从「20 张场景总览」和「14 组人物」下载真实原图，或直接使用压缩包内 assets/original_scenes/ 与 assets/original_characters/ 的 PNG 文件。先修 EX01 亭门和 EX07 布兔。
  2. 从 V01 开始：查看其「涉及人物图 / 场景图」，将相关图像真正放入 Pavo 画布的参考节点；本地文件路径不是模型能读取的图像引用。提示词中的 BG/A 等编号也不能代替真实图片绑定。
  3. 在生图节点复制「首帧生图提示词」，单独生成该视频片段第0秒的唯一画面。与资产卡逐项核对人物、门、手机左右手、兔耳补线和场景空间。
  4. 如当前视频模型界面支持尾帧，可在同一摄影机轴线上生成并上传「尾帧提示词」对应的静态图；对硬切蒙太奇不要用首尾帧强制把不同机位变成一次连续运镜。
  5. 确认画面无误后将首帧交给图生视频，复制「图生视频提示词」，选择16:9、5秒或6秒（实际以当前模型提供档位为准）。不支持6秒时可用支持的较长档生成后裁剪，不要强行将简单动作拉长。
  6. 带硬切的蒙太奇段（V01、V09、V12 等）按逐秒子镜条目分别制作静帧或微动短镜，再在剪辑软件合成目标5–6秒。黑场、字卡、准确字幕、电话号码、110、报时、音乐和对白尽量后期制作。
  7. 每段成功后在工作台标记「首帧通过」→「视频已生成」→「验收通过」，把失败原因记在备注框。不要连续修改无关多个变量；优先修首帧，然后只改动作或机位一个变量重试。
Pavo 不同模型、模式、账号可用功能可能变化。此助手不会调用网站 API，也不自动扣费或生成视频；具体积分报价、参考图上传数量、音频和首尾帧能力以你当前 Canvas 界面为准。

动作检查顺序：人物正确 → 空间站位正确 → 起始姿势稳定 → 单次动作物理合理 → 镜头运动稳定 → 结尾能衔接下一镜。先核人物和首帧，失败时不用再次支付生成视频。

离线工作台会在当前浏览器的本地存储中保存状态与备注；如果从不同路径打开、清理浏览器数据或更换设备，状态可能不共享。镜头内容的可编辑源文件是同包的 分镜数据_可编辑.json。
