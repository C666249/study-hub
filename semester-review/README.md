# 知序 · 学习工坊（Study Atelier）

这是根据用户上传的「大二上」复习资料整理的纯静态、手机优先学习网站。

## 内含什么

- 5 门学科：管理学、治安管理学、刑诉法、统计、警察公共关系
- 21 份原始课程文件，保存在 `assets/sources/`；对应文件名、学科及格式在页面的「我的 → 原始资料档案」中显示并可下载
- 从原文件提取的正文，按 368 段组织，保留原文字和资料出处；网页不删改资料表述，也不代替 PDF 中的图片、SPSS 截图、管理学模型图
- 744 道可判题题目，每题对应答案与解析；优先沿用资料中明确附带的答案，额外编写的题目标识「根据资料编写」
- 按学科、知识点、阅读资料的关联练习，以及顺序/随机/错题/收藏独立进度
- 手机端刷题页面使用固定底部上一题、下一题；多选题有「提交答案」
- 在「我的」内可导出与导入 JSON 学习进度；浏览器本地保存，不接入服务器、不需要登录

## 重要说明

- **这是一份复习工具，而不是经过现行法律逐条审核的法律数据库。** 历年资料、过时法规、课堂参考答案可能与现行法规或教师最终要求不一致。涉及法律内容，请以最新正式法规、教材、课堂要求为准。
- 原文件中的扫描图、管理学模型结构图、统计 SPSS 界面等不保证已转换成网页文字。页面提供原件下载，以便核对。网页阅读的部分包括文档可提取的完整正文，而非摘要。
- 无法从资料准确找到参考答案的旧试题没有伪装成自动判分题。它们仍在原资料与阅读正文中，可供查阅。
- 自动关联的知识点可能存在跨章节的松散关联，题目应优先依据原文件判断。补充的教学解释供学习使用，不替代正式教学答案。

## 使用方法

### 发布到已有 GitHub Pages 仓库（推荐）

1. 解压本包，把整个网站内容（`index.html`、`app.js`、`styles.css`、`favicon.svg`、`content/`、`assets/` 等）上传到 `C666249/study-hub` 仓库新建的 `semester-review/` 文件夹。
2. 确认仓库 GitHub Pages 已从 `master` 分支根目录发布。
3. 提交后，预计相对网址路径为 `https://c666249.github.io/study-hub/semester-review/`（**只有完成上传发布后才会生效，当前不代表已发布**）。
4. 不要覆盖已有 `discipline-exam/`、`discipline-article-quiz/` 文件夹；新网站是独立分区。

### 本机预览

- 最简单：在支持打开本地 HTML 的浏览器中尝试打开 `index.html`。
- 如本地浏览器禁止 `file://` 存储或脚本，可在网站文件夹下运行 `python -m http.server 8765`，再打开 `http://localhost:8765/`。
- 进度存储与网址（浏览器来源）相关；本地预览与 GitHub Pages 正式网址的进度不互通，建议在「我的」里导出 JSON 后再导入。
