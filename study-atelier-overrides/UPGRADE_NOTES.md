# 研习录 v0.2 — 资料与练习双向关联

## 数据保留

- 该版本只替换静态网站入口、交互和索引数据，不替换 `data.js` 的 21 份完整正文，也不删除 `originals/`、`assets/`、`preview/`。
- 57 个章节入口由已有 `topics.js` 以及原文段落组合创建；当无法可靠截取时，以原文入口兜底，不使用摘要代替。
- 题卡从用户来源文件提取：332 道，经核对来源答案的试题提供参考答案并自动判分；另有部分来源无可核验答案的题卡，仅供自测。
- 其他未结构化试卷、案例、统计操作题仍保存在“练题 → 完整原题档案”。
- 现有“解析”主要为参考答案与正确选项原文定位及对应章节跳转；非人工逐项专业审校，不应据此认定所有选项已有详细解析。

## 跳转路径

课程 → 章节 → 原文 → 本章题；题目 → 对应知识章节 → 跨学科知识网络；题目 → 来源完整文件；原文 → 关联章节、学科练习。

## 进度

`localStorage.atelier_v02_quiz` 保存全部/按学科/按章节/随机/错题独立进度、答案和错题。旧版 `lexis_progress` 与 `lexis_bookmarks` 保持兼容。

## 发布

静态文件覆盖于 `study-atelier-overrides/` 目录。原版 19MB ZIP 保持不变，由已有 GitHub Pages 工作流先恢复至 `study-atelier/`，再覆盖此目录中的升级源码。
