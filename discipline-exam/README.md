# 督察备考 · 校纪校规刷题网站

基于用户提供的《南京警察学院学生违纪行为处理标准.pdf》制作的独立学习网站（非官方平台）。无需安装依赖、构建工具或数据库。

## 目前包含

- **113道单选题**：95道条款扣分题 + 4道备注理解题 + 14道重点细节辨析题。
- 选择选项立即判断对错，显示**原始条款内容、扣分标准、PDF页码与项目**。
- 按知识模块及子项目分类刷题，可随机、顺序练习。
- 错题自动记录、错题重练、答对后自动移出错题本。
- 收藏/取消收藏题目、收藏夹专项复习。
- 完整原文学习页，涵盖**宿舍内务15条、行为规范75条、校级处分5档、备注4项**，支持搜索和折叠。
- 自动统计完成题量、正确率和进度。
- 手机上适配底部导航；支持键盘 1～4、Enter、F 快捷键。
- 完全静态：进度保存到当前浏览器的 `localStorage`；支持导出和恢复 JSON 备份。

## 直接运行

把整个文件夹解压后双击 `index.html` 即可使用。静态托管时，确保各文件保持在网站**同一级根目录**：

```
index.html
styles.css
app.js
data.js
favicon.svg
南京警察学院学生违纪行为处理标准.pdf
```

## Netlify 免费部署

1. 打开 [Netlify Drop](https://app.netlify.com/drop) 并登录。
2. **先解压 ZIP 文件**，将包含 `index.html` 的文件夹拖入页面（不要直接上传压缩包）。
3. 获得一个 `https://...netlify.app` 的公开链接，分享给同学即可。

## GitHub Pages 部署

1. 创建一个 **Public** 仓库（例如 `discipline-quiz`）。
2. 上传以上所有文件到**仓库根目录**，提交更改。
3. 打开 **Settings → Pages → Build and deployment**，Source 选择 `Deploy from a branch`，Branch 选择 `main / (root)`，保存。
4. 等待页面发布，网址通常为 `https://你的用户名.github.io/discipline-quiz/`。

## 数据说明

条款原文由用户上传的三页 PDF 文本图层逐行提取合并换行。专门保留了原文中的特殊说明、条款序号、扣分单位和处分标准。`data.js` 可编辑题库对应原文和章节配置，`app.js` 中包含额外细节题。

**注意**：题库仅对上传的这份文件负责；如果学校未来修订，应同步更新。本项目非官方发布。刷题记录默认为**每个人自己的浏览器单独保存**，不会通过 Netlify/GitHub 自动同步。清除站点数据、使用无痕模式或更换设备可能导致本地记录消失；建议定期在首页导出备份。
