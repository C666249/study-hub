# PPT Design · 可编辑演示文稿设计工坊

以**用户确认的效果图为视觉交付基线**，通过内容原生可编辑、独立高质量装饰分层和逐页对照验收，制作既有视觉完成度又可修改的 PPTX。

> 当前工坊版本 **1.2.0**（2026-11-09）；在 v1.1.0 上增量补充无重影分层重建、视觉资产盘点、按页编辑模式和强制逐页验收，旧规范保留。当前仍是**设计规范、两张已归档参考图和语义图标草图**，不是已经通过 1:1 验收的完整可编辑 PPTX 模板。

## 本轮新增的不可妥协原则

1. 设计图一经选定，制作 PPTX 时**不允许简化、丢失或替换**任何被用户认可的重要组件，尤其是警帽、天平、场记板、书本、盾牌等图标，以及参考图中的照片渐隐、纸纹、胶囊丝带、剪影与渐变。
2. **所有文案必须原生可编辑**；复杂视觉装饰可用**独立** PNG/SVG/位图，不强求每条装饰笔触都是 PPT 形状，但不得将整页截图冒充可编辑 PPT。
3. **必须从最终 PPTX 真正渲染逐页截图**，与效果图对照，留存差异和验收状态。不因肉眼“看起来差不多”就声称完全复刻。

## v1.2.0 新增硬规则

1. **禁止文字重影**：不能把带旧字的参考图当可编辑背景再叠文本框；先做干净底图、独立装饰和原生文字。
2. **先做四类视觉资产盘点**：主题图标（警帽/天平/盾牌/书本/场记板）、情境插画（公安楼体渐隐/记录本/人物）、纹理装饰（纸纹/远山）及信息组件（双色双折角/时间线/Venn/胶囊）均需逐项核对，不准省略。
3. **明确 A/B/C 编辑模式**：默认 A 分层可编辑；经用户授权可用 B 混合模式并将指定单页按 C 整图嵌入。指定整图页不可编辑，不得再次叠字；其他页面仍维持编辑能力。
4. **验收靠真正的 PPTX 导出**：逐页检查是否有旧字残影、图片被粗裁、图标漏项、渐隐照片丢失、文字溢出与标题折角不一致；未验证不声明完全复刻。
5. **旧版原样留存**：青金海岛风格、动画保护和旧的参考样例不因升级而被替换；本次新会话案例仅做方法与状态归档，未上传额外四张新效果图或一套已验证可编辑模板。

## 如何扩展风格库

在 `styles/` 添加新的独立 `.md` 风格包，将素材放入 `assets/references/` 和 `assets/icons/`，并向 `styles/catalog.json` 追加唯一 ID。原有风格始终保留，不自动成为所有项目的默认皮肤。
