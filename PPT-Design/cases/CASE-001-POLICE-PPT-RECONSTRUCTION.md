# CASE-001 · 《全楼都知道》PPT 高保真复刻与混合交付复盘

- **案例 ID**：CASE-001-POLICE-PPT-RECONSTRUCTION
- **适用风格**：`ACADEMIC-POLICE-PARCHMENT-001`（暖纸质公安学术风）
- **规范基线**：PPT Design Workshop v1.2.0
- **日期**：2026-11-09
- **状态**：**设计决策与故障归因已收录；最终本地/会话 PPTX 及其分层源码尚未在此仓库归档；1:1 可编辑模板仍未通过独立验收。**
- **用途**：总结一次真实 PPTX 设计往返中的失败与确认，供后续复刻任务防回退，而不是把一次用户授权的整页图片方案上升为默认规范。

## 1. 用户最终确认的目标

课程汇报主题《家庭纠纷调解与涉警舆情防控》，共 7 页。内容先简述《全楼都知道》剧情，再讨论案件的法律边界与困难、拍摄场景/运镜/演员心得，最后延伸到法理情、依法办理、舆情引导和社会面管控。视觉采用米白暖纸、藏蓝/铜棕/橄榄绿标题带、精致情境插画，不要单调纯色或科技未来风。

用户选定的设计语言不是泛化的「公安蓝」：**主题图标、场景插画、纹理与信息结构要共同复现参考页的精致度**。标志性元素包括双折角箭头、警帽、天平、盾牌、书本、场记板、柔和渐隐的公安建筑、警员背影、接处警记录本、纸纹和底部地形。

## 2. 失败链与根因

| 现象 | 根因 | 未来硬约束 |
| --- | --- | --- |
| 只有单箭头，参考是双色双折角 | 只按语义「箭头」替换，未按几何结构核对 | 按参考的折角数量、间距、配色与方向复刻；同套统一 |
| 警帽/天平/盾牌/书本/场记板消失或被简笔图代替 | 把图标视为可省略的点缀，没有预先清单 | G1 建标志资产清单；缺一项即未通过 |
| 右上公安建筑柔和渐隐消失 | 背景不分层，且只替换主色/卡片 | 建筑与透明渐隐属于独立环境素材，必须保留 |
| 截取装饰图片带旧文字或白底 | 从带字效果图粗裁，未校验 alpha 与边缘 | 不得把带旧字素材用于可编辑页；制作无残影独立素材 |
| 把旧效果图当整页底图，上方叠新文字 | 混淆整页参考与干净背景 | A 模式绝不叠字；C 模式整页图像不可编辑且不二次叠字 |
| 文案和装饰挤压、字号过小 | 用缩字迁就截图版式，未按内容重新布局 | 优化文本区域，必要时拆页并获授权 |
| 多次宣称「完全复刻」，用户实际看到差异 | 未执行真实 PPTX 与参考图逐页验收 | G3 导出对照并记录差异；不通过不得称完全一致 |

## 3. 三种编辑模式及选用依据

- **A 分层可编辑（默认）**：文字、数字、关键关系为可编辑对象；纸纹/插画/徽章可独立图像/矢量。需要从干净无旧字的层开始构建。
- **B 混合交付（本案例用户最终批准）**：保留原 PPTX 其他页及其可编辑性，指定第 5 页以完整效果图替换；后续仅统一其他正文页的双折角标题，去除「第一部分」「第二部分」等前缀。
- **C 指定页整图**：该页不求原生编辑，只保留完整视觉；须说明该页是图片且**绝不能再叠一层同文案文本框**。

**用户明确说「这张图直接放进去，不需要可编辑了」时，继续追求该页的全分层会违背当前授权。** 但这不影响其他页原有编辑属性。

## 4. 必须逐页检查的视觉资产

1. Iconography：警帽、天平、盾牌、打开书本、电影场记板、书写工具、气泡/引号、靶心、纸夹。
2. Editorial Illustrations：公安楼体（尤其右上角明暗/渐隐）、民警背影、楼道、居民楼、接处警记录本与钢笔。
3. Textures & Decorative Elements：米黄色纸纹、暖边光、地形/山峦/街景、金线、渐变遮罩。
4. Infographic Components：双折角、大标题、胶囊标题带、细线卡片、金章、时间线、Venn 三圆、错误/建议红绿对照。

每项必须记录「参考 → 真实 PPTX → 匹配状态 → 格式/可编辑性」，不能只写「已加图标」。

## 5. 交付检查与证据要求

- 来源：正式参考页原图与用户批准的修改范围；不从手机截图把通知栏、水印或文件名字符串当页面内容。
- 结构：按页检查文本框、图形、独立图片对象数量。原版非目标页尽量仅改标题前缀与折角，不重建整套。
- 视觉：实际导出 PPTX 每页，检查旧文字、边缘、缺图标、透明背景、字体替换和图层遮挡。
- 可信度：记录实际检查所用工具与目标软件；未在 Windows PowerPoint/WPS 测试时必须列出「目标软件待验证」。
- 最终形态：可编辑页和整图页分开描述，不能把「有图片」误报为「可编辑」。

## 6. 风格库归档边界

现有仓库已归档的正式参考只有 REF-01 / REF-02 两张；聊天中曾出现其他封面与时间线效果图、多个生成 PPTX 版本和相关素材，但**截至本案例文档提交，它们未作为完整原生资产包进入仓库**。引用它们时不得称为已在 GitHub 注册的可复用高清资源，也不自动宣称 1:1 模板已完成验收。

当前案例仅是技术与设计教训、用户最终批准的混合交付方案。未来如获授权及源文件，再将 PPTX、渲染图、分层素材与核验结果单独补档；保留本案例 ID，并升级验证状态。

## 7. 可复用结论

> 已确认效果图就是视觉验收基线；**可编辑性和视觉保真不能靠一张旧图叠文字来兼得**。优先干净分层；用户明确许可时，才允许指定页整图；无论哪种模式都要保留关键图标和场景元素、使用真实渲染结果验收并如实标注编辑边界。
