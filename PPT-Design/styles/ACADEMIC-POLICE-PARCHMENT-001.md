## 一、设计 DNA

- **画幅：** 16:9 横版，当前参照 1536×864；创建 PPTX 通常用 13.333×7.5 英寸，渲染后同尺寸对比。
- **背景：** 低对比暖米白纸张，微细纸纹/颗粒与暖金色边角环境光，不是纯白平面。
- **标题：** 深海军蓝或深棕近似宋/衬线气质大标题，前置双折角 `»` 的铜棕/蓝色双层图形；正文黑褐色，密度偏高但分栏有序。
- **分区：** 半透明暖纸卡片、极细描边和柔和投影，标题用海军蓝/铜棕渐变胶囊丝带，左侧圆形主题徽章。
- **强调：** 深蓝用于理性与法律边界；铜棕用于故事、复盘、人物；青绿色表示正确建议；赭红色表示不当表达；暗金用于法/理/情章标。
- **信息表达：** 先讲事件与困境，再给证据、比较与实践启示；“高信息密度但强层级”，不是空泛装饰拼贴。
- **底部：** 沙金色地形/建筑/远山、斜坡纸影、飞鸟或人物剪影。仅在有位置的参考页面出现，不每页机械复制。

## 三、REF-01｜法、理、情如何平衡

**结构：** 顶部细标题条与徽章；超大深蓝标题前是双色双折角；下方一条浅金色引言背景卡；页面中段三张大小接近的垂直卡片；底部横向金色圆角启示条；建筑、长城山景、浅金色波浪、飞鸟点缀边角。

- **左卡：** 标题“**三者的内涵与侧重**”，三组“法／理／情”圆形金章，竖向细线，文字按行清晰分区。
- **中卡：** 标题“**三者的关系：相辅相成、缺一不可**”，一张半透明三集合 Venn 图；深蓝“依法处理”、暖橘“舆情引导”、柔绿“社会面管控”，三圆叠加不可被纯白平面三栏替代；中央有**独立警帽**图标。
- **右卡：** 标题“**从剧本中的教训看更恰当的处置表达**”，上半红色错误表达卡片与叉号，下半绿色恰当表达卡片与勾号；右侧独立问题/改进要点小栏。必须保留红绿分区，不得混成一段文章。
- **下方：** 金棕“**实践启示**”胶囊+靶心图标，后接长句总结；保留浅金流动底部地形与边缘细线。

**对照重点**：三栏卡片横向尺寸、深蓝胶囊标题大小、Venn 透明叠色、警帽/天平/靶心/气泡/盾牌、右卡红绿对照和底部山景不能遗漏。

## 四、REF-02｜民警失言与所长的教导

**结构：** 顶部深棕大标题与双折角；右上**公安楼照片与暖纸背景之间的柔和渐隐**；中上左右信息布局：左侧失言回顾、右侧所长教导及浅金色便签；下方左侧教训与思考、右侧“我们的认识”三条结构卡；底端铜色层叠山峦，右下双警背影。

- **上左：** **电影场记板**为分区标志，赭棕丝带“**一、失言情节回顾**”；保留引言、米色引语框、大号引号及后续舆情叙述。
- **上右：** **警帽**图标与“**二、所长的教导（剧中对话核心）**”丝带；三行对话分别用人物小标识与横向虚线间隔，最后一句深棕加粗并有细下划线；右边淡金便签“所长进一步强调”保留纸夹、三点列举和阴影。
- **下左：** **打开的书本**线描图标，棕色丝带“**三、教训与思考**”，独立圆角内容卡与重点字色。
- **下右：** 大号**天平徽章**，横向铜棕丝带标题；下方三条法、理、情有圆形金章、浅灰细分隔线和独立正文。
- **环境图层：** 顶部公安楼体照片有透明渐隐、树枝透光；右下警员背影不应变成普通剪影人形或被舍弃；底部山峦/纸纹保留，但正文可读性优先。

**对照重点**：右上公安楼必须存在且渐隐自然；场记板、警帽、书本、天平徽章四种显著标志完整；右侧便签与纸夹独立；页面整体暖棕、纸感层次、上下栏布局准确。

## 五、进入可编辑 PPTX 的技术边界

- **必须原生可编辑**：所有中文/英文字、数字、日期、法理结论、引语、分区标题、红绿表达对照、三条法理情结论；核心列表、卡片和原生 Venn 圆应可选取编辑。
- **建议原生或矢量**：标题丝带形状、徽章外圈、金色细线、卡片边框、箭头、标签、三圆透明底，优先 PPT 形状/SVG，需说明 SVG 在 PowerPoint/WPS 是否可拆改。
- **可独立位图**：纸纹、楼体实景、山峦/警员剪影、部分复杂徽章和精致小图标；不得与文字合成整页截图。位图足够高清，边缘不糊，独立图层可移动、调整、替换。
- **目标工具与字体**：中文用户如指定微软雅黑必须遵守，英文依用户单独要求；未指定时选择兼容的宋体/无衬线搭配，先渲染验证，不能让缺失字体破坏换行。
- **交付验收**：每页导出 PNG，和对应 REF 参考逐页并排检查；附逐项组件核对清单和可编辑性报告。只有真实打开 PPTX 检查过，才可宣布达到视觉标准。

## 六、开放扩展

以后新增任何风格，用唯一 ID 增量录入 `styles/catalog.json`，不覆盖本风格。每个新包至少含：参考图/来源、主色体系、字体层级、信息密度、装饰图层、组件索引、版式族、可编辑边界、验收状态。没有原始资源时明确写缺失，绝不把概念描述伪称可复用的完整组件资产。

## 七、v1.2.0 补充｜完整视觉语言与版式族

本次《全楼都知道》的设计复盘进一步确定：该风格不是单纯“米黄背景+卡片”，而是一套四种共同工作的视觉资产系统：

- **Thematic Iconography / 主题图标**：警帽、天平、盾牌、书本、电影场记板、纸夹、靶心等。图标具备铜棕雕刻/浅金浮雕或海军蓝细描边的家族一致性；**不可用常见 emoji 代替，也不可粗糙截取带底字的参考图碎片**。
- **Editorial Illustrations / 情境插画**：柔和渐隐的公安局楼体、双警背影、居民楼与楼道、接处警记录本和钢笔。构图中这些是边缘环境层和主题标识，不是可以无视的填充物。
- **Textures & Decorative Elements / 背景纹理和装饰**：纸张细颗粒、暖光、浅金地形、飞鸟、树枝、照片蒙版与自然过渡。参考图中的**右上公安楼体渐隐**是强制检查项。
- **Infographic Components / 信息可视化组件**：双色**双折角**标题箭头、铜棕/蓝/橄榄绿圆角丝带、三圆 Venn、时间线、金色编号、红绿处置表达对照、便签/引语卡、页脚结构。

### 该风格的分层复刻准则

1. 先从干净无字的纸纹/环境层开始，再添加独立情境插画与主题图标；**禁止带旧字整页参考图作底后叠新文字**。
2. 用户特别批准的指定页可以直接使用完整效果图作不可编辑图片，但不能在那页再叠一层相同文字。整套其他页仍应保留各自的编辑方式。
3. 图片提取须检查残余原文字、缺角、压缩噪声、白底伪透明及截断的徽章或场记板；不合格素材需修整或重绘，而不能直接交付。
4. 正式参考库存目前仍只有上面 REF-01、REF-02。此处的 A/D 版式属于**已分析的视觉方法**，不能冒称已保存了四张独立高清参考及其完整分层源。
5. 逐页检查清单见 [`../VALIDATION.md`](../VALIDATION.md)，具体失败案例见 [`../cases/CASE-001-POLICE-PPT-RECONSTRUCTION.md`](../cases/CASE-001-POLICE-PPT-RECONSTRUCTION.md)。
